## B06 — Manim: Circularity Loop (~14s)
*Loop: Define → Sample → Redefine → (back to Define). Terracotta loop arrow.*

The circularity trap runs like this: sketch the construct, pull candidate postings, notice a pattern, update the construct to match. Repeat. The coding scheme never gets a chance to fail. When it can't fail, it's not a coding scheme — it's a retroactive label.
