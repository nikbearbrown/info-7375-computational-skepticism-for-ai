**What this is.** Every generation prompt. There are none: each image is a drawn isometric illustration in Manim (`scenes.py`, the ISO KIT). No stills, no clips, no photographs, no portraits of Descartes, no Higgsfield spend.

**Your Turn (BHTF)**, shown and read in full (spoken with "paste them" for `[paste them]`):

```
Here are five claims my work relied on this week: [paste them]. For each one, help me say what it would cost if it were wrong, and rank them by that cost. Then, for the top one or two only, ask: what would have to be true for this to be wrong? List conditions I can check.
```

Checks shown under it (the viewer runs these themselves):
- Check: are the top two the ones that could hurt?
- Check: could you test each condition this week?
