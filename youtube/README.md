# Computational Skepticism exam-prep films

[Watch the ordered exam-prep playlist](https://www.youtube.com/playlist?list=PLelOldL5q7F0).

The first three films are unlisted, followed by the existing 13 public topic films:

1. [Five Questions for Every Case](https://youtu.be/iOLLb6zAQVg)
2. [Ten Multiple-Answer Questions](https://youtu.be/tuKOHbIa0F0)
3. [Your Practice Project](https://youtu.be/Jw39Pb5ymCQ)

[Copy the self-contained exam-generator prompt](../fall-2026-exam/EXAM-GENERATOR-PROMPT.md) into a Claude Project to generate starter practice questions. The working format is five cases with five directed questions each (50 points), plus ten multiple-answer items (50 points).

The prompt is a draft with an independent assistant-agent sample check, not a live Claude Project test. The walkthrough is a source-based illustration, not a live session recording. Topic-scope discrepancies remain explicitly documented in the prompt.

This repository contains beat sheets, scripts, shot lists, sources, timing metadata and QA records. Rendered audio/video and generated render caches remain outside GitHub. Build-time records describe their original stage; `exam-intro-processing-final.json` and per-film `YOUTUBE-VERIFICATION.json` record the subsequent upload/processing results.

Private exam keys, validation answer keys, credentials and unrelated local work are not part of this publication. Existing practice papers remain historical exercises, not revised-format mock exams.
