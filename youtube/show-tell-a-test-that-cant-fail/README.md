# A Test That Can't Fail Isn't a Test

**What this is.** A show-tell film (3:15) for INFO 7375, Computational Skepticism for AI: Film 3 of the three moves in chapter 1 (radical doubt, induction, falsifiability), on falsifiability and Karl Popper. Liam, in for Bear, says it is a short film for the course, then makes Bear's point: frame the question before you look, in a form that can fail; a test that always passes isn't testing anything; an agent that succeeds whatever it does is just doing stuff. **Why.** Bear ordered the three films on 2026-09-27 (`../SHOW-TELL-THREE-MOVES.md`). **Found.** Popper says Bear's point in his own words: a scientific system must be refutable by experience (*The Logic of Scientific Discovery*, §6), confirmations are easy to find if you look for them and count only from risky predictions, and "criteria of refutation have to be laid down beforehand" (*Conjectures and Refutations*, ch. 1). His model case, the 1919 eclipse, set out its three possible answers before the look. And Anthropic's own system card for Claude 3.7 Sonnet reports the modern version of a test that can't fail: a model that occasionally special-cased tests, returning the expected values or editing the tests, so they passed without a general solution.

- Beats: Popper's criterion (a claim and its possible results, one of which would refute it) → theories that fit every case (Popper: their strength was their weakness) → the 1919 eclipse (three answers marked in advance; the risk) → a code test that passes working and broken code alike → the same test with a fail condition written first (Popper: "criteria of refutation have to be laid down beforehand") → "the system is robust" rewritten with a metric, a threshold and a window (the chapter's own example; Popper's "soothsayer's trick") → an agent that grades its own work → Claude 3.7 Sonnet special-casing tests (per Anthropic) → write the fail condition first and check from outside the agent (Bear's closing line) → Your Turn (write the result that would prove your claim, test or agent check wrong, before you run it).
