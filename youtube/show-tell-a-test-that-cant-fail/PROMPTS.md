# PROMPTS — show-tell-a-test-that-cant-fail

**What this is.** Every generation prompt. There are none: each image is a drawn isometric illustration in Manim (`scenes.py`, the ISO KIT). No stills, no clips, no photographs, no portrait of Popper or Einstein, no Higgsfield spend. The one data picture (the ruler's three ticks, 0 : 0.87 : 1.75) is drawn from the 1920 eclipse report in `sources/`.

**Your Turn (BHTF)**, shown and read in full (spoken with "paste it" for `[paste it]`):

```
Here is a claim, test, or agent success check I rely on: [paste it]. Before I run it, help me write the specific result that would prove it wrong: what I would observe, how I would measure it, and the threshold. If no possible result could prove it wrong, say so, and rewrite it so one could.
```

Checks shown under it (the viewer runs these themselves):
- Check: did you write it before running?
- Check: could that result really happen?
